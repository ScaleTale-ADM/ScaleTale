# ScaleTale

**ScaleTale** is a free indie space action game developed with Python and Pygame.

**Current Public Beta:** `V1.1.1 (V111) — Celestial Atelier`

**Platform:** Windows 10 / 11 (64-bit)

**Distribution:** Official Windows Installer (`ScaleTale Setup.exe`)

ScaleTale combines arcade space combat, cinematic boss fights, planetary exploration, mysterious Scale-0 events, cockpit scanning, dynamic music, sound effects, and collectible boss rewards.

With the release of **V1.1.1**, ScaleTale introduces its official Windows installer, making the game easier to install, launch, and enjoy.

## Installation — Windows

**Starting with V1.1.1, ScaleTale is officially distributed through a Windows `.exe` installer.**

Players no longer need to manually install Python, configure Pygame, open IDLE, or execute terminal commands.

### How to Install

1. Open the latest ScaleTale release in the GitHub **Releases** section.
2. Download the official installer: `ScaleTale Setup.exe`.
3. Run the installer and follow the on-screen instructions.
4. Complete the installation.
5. Launch **ScaleTale** using the desktop shortcut (if created) or the Windows Start menu.

You are now ready to explore the ScaleTale universe.

### Important Information

- The installer includes the game and its required dependencies.
- Python and Pygame do not need to be installed separately.
- The previous `.zip` distribution format is no longer required for regular Windows installations.
- Future Windows releases will be distributed through updated `.exe` installers.
- Automatic updates are not currently supported. New versions must be installed manually using their corresponding installer.

## Troubleshooting — OpenGL Errors

If ScaleTale fails to initialize its graphics environment or displays an OpenGL-related error, follow these steps:

1. Open **Device Manager → Display adapters** to identify your graphics hardware.
2. Download and install compatible graphics drivers recommended by your computer manufacturer or GPU manufacturer:
   - Intel
   - NVIDIA
   - AMD
3. Restart your computer.
4. Launch ScaleTale again.

Windows Update may also provide graphics drivers through optional updates.

**Updating your drivers may resolve OpenGL-related problems if your hardware supports OpenGL 3.3. However, updating drivers cannot guarantee compatibility with unsupported hardware.**

The current 3D rendering system uses OpenGL and does not yet include a DirectX or Vulkan alternative.

For additional information:

- [Official OpenGL Documentation](https://wikis.khronos.org/opengl/Getting_Started)
- [Microsoft Windows Driver Support](https://support.microsoft.com/en-us/windows/hardware/drivers/automatically-get-recommended-and-updated-hardware-drivers)

### Still Experiencing Problems?

If the issue persists:

1. Use the diagnostic tool included with ScaleTale.
2. Save or copy the error message.
3. Identify your graphics card model.
4. Report the problem through our Discord community.

Please remember that startup errors may have different causes and are not necessarily related to OpenGL.

   - NVIDIA
   - AMD
3. Reinicia el ordenador.
4. Intenta iniciar ScaleTale nuevamente.

**Actualizar los controladores puede solucionar problemas relacionados con OpenGL si tu tarjeta gráfica admite OpenGL 3.3. Sin embargo, no garantiza que un hardware incompatible pueda ejecutar el juego.**

El sistema de renderizado 3D actual utiliza OpenGL y todavía no cuenta con una alternativa mediante DirectX o Vulkan.

- [Documentación oficial de OpenGL](https://wikis.khronos.org/opengl/Getting_Started)
